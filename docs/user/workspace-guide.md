# Workspace Guide

## Portfolio

Use the portfolio for cross-program maturity, source freshness, WIP, risk denominators, and shared
pressure. Published and candidate metrics are never combined.

## Program tabs

- Overview: program posture and next action.
- Schedule: published matrix or timeline; locked when no model is published.
- Flow: current routing position and work-center movement.
- Units: unit and shop-order evidence.
- Resources: route-specific capacity and tooling inputs.
- Assumptions: readiness, provenance, review dates, and gaps.
- History: model epochs and lifecycle evidence.

## Supporting views

The Factory Map is a visual overlay and does not alter forecasts. Scenarios show controlled what-if
changes. Resource details identify assumption ownership. Why panels explain the inputs affecting a
unit rather than presenting an unexplained date.
