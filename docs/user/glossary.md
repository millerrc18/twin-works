# Glossary

| Term | Definition |
| --- | --- |
| As-of | Timestamp represented by the current input snapshot |
| Candidate epoch | Immutable model definition under evaluation but not necessarily published |
| Commitment-ready | Lifecycle state eligible for authorized publication |
| External reserve | Capacity retained for demand not represented as tracked TwinWorks WIP |
| Occupancy lease | Exclusive hold on a tool or station slot between approved events |
| P50 | Central corrected forecast date |
| P80 | More conservative corrected forecast date |
| Physical pool | One real labor, machine, tooling, station, or space resource identity |
| Planning basis | Approved target type used for comparison, such as RTG slots or contract dates |
| Published epoch | Commitment-ready model selected for operating forecast output |
| Quarantine | Append-only exclusion of inconsistent source records pending later evidence |
| RTG | Return-to-Green operating plan |
| Shadow | Candidate calculation isolated from published commitments and leadership KPIs |

See [Forecast Method](/handbook/forecast-method) and
[Planning Basis and Publication](/handbook/planning-basis) for the governing date semantics.
