# Getting Started

TwinWorks is the operating view for Elevator, Aeronose, and Aegis manufacturing forecasts. It
combines current unit position, a finite-capacity schedule, governed assumptions, and measured
forecast correction.

## Begin with the portfolio

1. Confirm the data source and as-of time in the header.
2. Review each program's lifecycle, planning basis, WIP, stalled units, and risk denominator.
3. Open the program workspace for unit-level work.
4. Treat missing or provisional resource inputs as model limitations, not as available capacity.

## Choose the correct target

- Elevator and Aeronose compare against approved RTG plan slots.
- Aegis compares against contract dates.
- A candidate or observation model never publishes dates.

Read [Planning Basis and Publication](/handbook/planning-basis) before using a date for a commitment.

## Escalate honestly

Use the Why panel to distinguish physical work, cure/dwell, capacity waits, and model adjustment.
Use Resources for assumption ownership and review dates. A red or missing input is a request for
evidence, not permission to substitute a default.
